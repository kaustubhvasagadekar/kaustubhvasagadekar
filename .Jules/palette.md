## 2024-06-21 - [Accessibility: Enhancing Color Contrast for Brand Elements]
**Learning:** Using a primary brand color with a contrast ratio below 3:1 (like #FF6B82) for buttons and badges with white text violates WCAG AA standards. Transitioning to a more saturated shade (like #C2185B) provides a 5.91:1 ratio, ensuring readability for all users while maintaining the brand's aesthetic.
**Action:** Always verify contrast ratios for primary UI actions and informational badges. Use tools or mathematical checks to ensure a minimum 4.5:1 ratio for small text on colored backgrounds.
