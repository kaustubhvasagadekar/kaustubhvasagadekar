## 2026-08-07 - Accessibility of original/discounted prices and labels consistency
**Learning:** Using low opacity (e.g., `opacity: 0.3` on dark text) to style original/discounted prices leads to extremely poor color contrast (failing WCAG AA standards), while using `<span>` with visual line-through styles is opaque to screen readers who cannot perceive that the price is "deleted" or "original". Moreover, grammatically incorrect labels (like "2 Unit" and "3 Unit") and mathematical inconsistency across package options can cause cognitive friction and doubt about the discounts.
**Action:** Always replace `<span>` elements for original/discounted prices with semantic `<del>` elements for screen reader compatibility, use a solid color (e.g., `#757575`) with >= 4.5:1 contrast, correct label grammar (e.g., "2 Units", "3 Units"), and ensure that the original price values scale mathematically in proportion to unit quantity (e.g. $24.00, $48.00, $72.00).
