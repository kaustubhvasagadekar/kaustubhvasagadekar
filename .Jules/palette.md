## 2025-05-15 - [Semantic and Interactive Micro-UX]
**Learning:** Using semantic HTML like `<del>` for discounts and `:focus-within` for card-based selections significantly improves accessibility with minimal code. Proper grammar in unit labels (e.g., "2 Units") is a small but vital touch for professional UX.
**Action:** Always check pluralization in dynamically listed items and use `:focus-within` to ensure parent containers provide visual feedback for nested interactive elements.
