## 2026-07-07 - Focus-within Pattern for Choice Cards
**Learning:** For choice-based UI components (like BOGO offer cards) where the interactive element (radio button) is nested within a larger container, using `:focus-within` on the container provides a much better visual indicator for keyboard users than just focusing the small radio button itself.
**Action:** Always implement `:focus-within` styles on selection containers to ensure keyboard focus is clearly visible and professional.
